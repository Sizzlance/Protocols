# Network Protocols & Utilities

Набор консольных утилит на Python для работы с сетевыми протоколами через низкоуровневые интерфейсы (sockets).

## Описание инструментов

### 1. PortScan
Многопоточный сканер портов с поддержкой TCP и UDP.
* **Функционал**: Сканирование диапазонов портов и идентификация прикладных протоколов по сигнатурам (HTTP, SMTP, IMAP, POP3, DNS, NTP).
* **Реализация**: Использование модулей `threading` и `queue` для параллельной обработки.

### 2. Mod_Tracert
Утилита трассировки маршрута с обогащением данных через WHOIS.
* **Функционал**: Определение пути следования пакетов с использованием RAW-сокетов и ICMP.
* **Особенности**: Самостоятельная сборка ICMP-пакетов, вычисление контрольных сумм и вывод информации об организации (ISP), ASN и стране для каждого узла.

### 3. IMAP Client
Клиент для прямого взаимодействия с почтовым сервером.
* **Функционал**: Аутентификация (LOGIN), выбор ящиков (SELECT), поиск (SEARCH) и получение сообщений (FETCH).
* **Безопасность**: Реализована поддержка SSL/TLS через модуль `ssl`.

### 4. SNTP Server & Client
Реализация протокола синхронизации времени.
* **Server**: Обработка запросов с возможностью задания временного смещения (delay).
* **Client**: Получение и интерпретация 64-битных временных меток NTP.

### 5. Whois_request
Прямой запрос регистрационных данных IP/доменов через протокол WHOIS (порт 43).
